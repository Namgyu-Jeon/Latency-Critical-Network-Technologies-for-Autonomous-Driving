# Simulation Video Links

This document provides supplementary video links for each simulation case.  
Each video shows one spacing-based platooning simulation run used to evaluate whether a collision occurs under different network configurations.

The simulations were executed with different vehicle gaps because autonomous driving safety depends not only on network performance but also on the physical braking distance between vehicles.
